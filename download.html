What you need

  • A 64-bit computer running Windows 11 or Ubuntu 24.04. 32-bit computers can’t run Jukoke.
  • A processor from 2014 or newer. Check before party day, not on the afternoon of.
  • 16 GB of memory and 256 GB or more of storage is comfortable; most of the space is for your songs.
  • A WiFi network your guests’ phones can join, and an internet connection if you plan to play songs from online sources.
  • A TV or monitor and a sound system, connected to the computer.

First launch

  1. Start Jukoke. The party screen opens with a QR code.
  2. Scan the MC code with your phone and enter the MC password to open the host dashboard.
  3. Tell guests to scan the guest code, pick a nickname and a 4-digit PIN, and add a song.

Windows shows a “Windows protected your PC” message

New apps that Windows hasn’t seen many times often trigger this screen. Choose More info, then Run anyway. If you’d like to check the file first, compare its SHA-256 value with the one above.

Checking the download

On Windows, open PowerShell in the folder with the file and run Get-FileHash .\Jukoke-Setup.exe. On Ubuntu, run sha256sum Jukoke-Ubuntu.deb. The result should match the value shown above.

Uninstalling

Use Windows Settings → Apps, or Ubuntu’s Software app. Your songs, history, catalog and settings are left in place; delete them yourself for a completely clean slate.
